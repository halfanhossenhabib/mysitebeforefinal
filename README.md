# Halfan Hossen Habib Portfolio

A modern static GitHub Pages portfolio for Halfan Hossen Habib. The site presents a dark futuristic personal homepage with a lightweight interactive Three.js hero, glassmorphism project cards, animated about badges, social links, and a small "Do not Click!" easter egg.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- Font Awesome
- Google Fonts
- GitHub Pages

## Local Setup

No build step is required.

For the easiest browser preview, open `portfolio-open.html` directly in your browser.

For normal GitHub Pages development, serve the folder with any static web server:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Build and Deploy

This is a plain static site, so there is nothing to compile.

1. Edit `index.html`, `styles.css`, or `script.js`.
2. Test locally with a static server.
3. Commit and push to the GitHub Pages branch, currently `main`.
4. GitHub Pages will publish the updated files automatically.

`portfolio-open.html` is a one-file preview copy for opening locally in a browser. GitHub Pages should still use `index.html`, `styles.css`, `script.js`, and `favicon.svg`.
