GitHub Pages guide

Build it, upload it, publish it.

Start with a tiny HTML file, place it in a public GitHub repository, then let GitHub Pages turn it into a real link you can share.

  1. Create a file Open Notepad or VS Code and write your HTML code. Use ChatGPT if you need help shaping the first draft.
  2. Save it Name the file index.html so GitHub Pages knows what to open first.
  3. Create your GitHub account Go to github.com and sign in or create a new account.
  4. Make a public repository Create a new repository, give it a clear name, and set it to Public.
  5. Upload your site file Choose “Upload an existing file” and drag your index.html into the repository.
  6. Commit the change Click “Commit changes” so the file is saved into the repo.
  7. Open Pages settings Go to Settings, then Pages from the left sidebar.
  8. Deploy from main Change Branch from None to Main, then click Save.
  9. Wait for the link Give it 1-2 minutes. Your website link will appear near the top of the Pages screen.
